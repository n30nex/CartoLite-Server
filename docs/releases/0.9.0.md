# 0.9.0 — Make Terminal your own

- Add Terminal options inside Display, with BBS, Amber, Green, CGA, EGA and Cel-shaded presets.
- Adjust geography, node, packet, route, label and interface colours with a picker, hex value and hue/saturation/lightness sliders.
- Choose system mono, Typewriter, VT323 console or Silkscreen pixel fonts, with map size, weight and interface scale controls.
- Draw Braille, ASCII, pixel-block or cel-shaded maps. Keep routes sharp above the map and choose glowing characters or smooth live packets.
- Adjust background brightness, place labels and live glow independently; keep the existing six route styles and advanced controls.
- Preserve existing preferences and synchronize Terminal profiles across tabs. The editor retains readable colours and reset controls.

Fonts are bundled locally under SIL OFL 1.1; no remote font service is used. No
backend endpoints, traffic fields, dependencies, packet/audio timing or native APK
changes. Builds, tests and screenshots run only in Actions. Release publication
and deployment evidence will be recorded in the published release.

Terminal defaults match the owner-selected screenshots: routes, live packets,
heatmap, node/place labels, roads and buildings on; clusters, regions, Topo and
3D off; 15-minute routes and 15% Topo shading. Fine ANSI/BBS Braille, Spectacle,
Complete detail, High graphics, system motion, standard text and Neon routes.
Layer/display settings are independent from Map/Netgraph, and saved Terminal
customizations remain. Reset all display settings restores these Terminal defaults.
