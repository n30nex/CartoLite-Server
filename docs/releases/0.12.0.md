# CartoLite Server 0.12.0

- New Pachinko page: one luminous dot per packet, six type lanes, peg contacts, labelled buckets, overflow and a drain action.
- Generated metal and enamel materials improve machine shading while packet colors remain distinct.
- Firehose prewarms graphics before collecting packets, predicts dense-pile decorative load, and keeps the existing physics, topology and input-response limits.
- Chronoscope gains a full 3D orbit/pan/zoom camera and a bounded session sculpture of settled packet shapes. Flat/Slice inspection, freeze, clear, selection and a 2D graphics fallback remain available.
- Icon navigation groups Chronoscope, Firehose and Pachinko under Experimental. Only operator-enabled pages appear. Phones retain one compact view picker.
- Large static assets stream without copying the whole response into a new buffer; HEAD requests do not read asset bodies.

Worldwide operators can enable Pachinko with `EXTRA_PAGES=pachinko`, or append it to an existing comma-separated list. Map and Netgraph remain the defaults; existing selections are preserved. Use this release’s Compose file and keep your environment and data volume.

Exact tested artifacts and final qualification evidence are recorded in the published release notes. All builds, tests and browser screenshots run in Actions. Tested AMD64 and ARM64 images are promoted without rebuilding.
