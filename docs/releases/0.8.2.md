# 0.8.2 — Correct default image for new installs

The Compose file and environment example now select 0.8.2. They previously
selected 0.7.2, so copying the install files without changing the image could
start an older release without Terminal. CI and release promotion now reject
installer defaults that disagree with VERSION and the frontend package metadata.

Includes the Terminal detail improvements from 0.8.1: clearer roads and routes,
vegetation and built-up textures, finer cells, crisp live packets and labels that
fit above or below nodes on small screens.

For existing installs, set `CARTOLITE_IMAGE=ghcr.io/n30nex/cartolite-server:0.8.2`
in `.env`, then run `docker compose pull` and `docker compose up -d`. Keep the
existing data volume. New installs can use the attached Compose/environment
files and enter their MQTT settings. AMD64 and ARM64 remain supported.
