# 0.8.3 — Clearer, brighter Terminal activity

- Dim background water, land textures and roads so the network stands out.
- Preserve strong route colours at dense zooms and give node markers a clear,
  bold silhouette. Labels sit above live effects.
- Add bounded, coloured glow and white-hot character cores to live activity.
  Preserve colour in faint trails and fade using the original packet frame.
- Respect Spectacle, Calm, Minimal, graphics quality and reduced motion.
- Remove hard frontend, worker, geography and container build-size ceilings by
  owner request. Report sizes; retain asset integrity/isolation, runtime timing,
  7,000-route, privacy, security and installation checks.

Live packet timing, audio, route meaning and saved preferences are retained.

The installer files select 0.8.3. Existing installs can set
`CARTOLITE_IMAGE=ghcr.io/n30nex/cartolite-server:0.8.3` and run
`docker compose pull` followed by `docker compose up -d`. Keep the data volume.
