# 0.8.1 — More readable Terminal maps

- Preserve vegetation and built-up areas as subdued character textures.
- Recover thin roads and routes between character samples; prevent bright routes
  from colouring an entire underlying water or land cell.
- Use finer cells on large displays, within the existing 16,000-cell ceiling.
- Keep labels independent of map cell size, measure Unicode text and reserve
  collision space. Node names are pale; place names remain yellow.
- Preserve live packet timing, layer choices, sound, Find and inspection.

Validation uses synthetic land, water, roads and Unicode labels on desktop and
mobile, plus the existing 4,000-node / 7,000-route performance gates. All builds,
tests and screenshots run in Actions. No new dependencies or higher size limits.

Update the published image to `ghcr.io/n30nex/cartolite-server:0.8.1`, then run
`docker compose pull` and `docker compose up -d`. Existing settings and the data
volume are retained; AMD64 and ARM64 remain supported.
