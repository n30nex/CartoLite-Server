# CartoLite Server 0.11.1

- Rework Firehose into tiny luminous packets, crisp chains and short motion trails.
- Add arrival light pulses, a glowing funnel and brief landing rings.
- Replace the heavyweight rigid-body solver with bounded particle contacts, ropes and sleeping, improving full-pile responsiveness.
- Smooth variable-rate physics snapshots and align packet inspection with the displayed positions.
- Remove the unused WASM dependency and worker permission. Preserve live-only intake, packet meaning, pause, sounds and existing saved settings.

Available through the existing AMD64/ARM64 published-image installation.

Worldwide now defaults to Map and Netgraph. Enable any subset of Terminal, Chronoscope and Firehose with `EXTRA_PAGES`; the dock, phone picker and direct page URLs follow that setting. Labs remains Canada-only.

**Upgrade note:** download this release’s `compose.yml` while retaining `.env` and the data volume. To keep all five pages, add `EXTRA_PAGES=terminal,chronoscope,firehose` before recreating the service. Without it, extra pages default to off. Saved preferences and checkpoint data are retained. [Details](../deployment.md#choose-the-pages-on-your-server).
