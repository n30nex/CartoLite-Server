# 0.8.5 — Clearer controls and help

The second UI/UX roadmap package improves the controls around the existing scenes.

- Help & controls is available from Display on desktop and the compact View menu on phones. It explains live versus historical activity, observer-only pulses, 3D, Follow and keyboard controls. Back/Escape preserve node selection.
- Terminal shows its own palette/character controls and keeps ordinary Map style and interface settings saved for the other views.
- Netgraph shows active region/focus filters and hidden routes even when menus are closed. Clear filters keeps route visibility and the saved region layout.
- Browse all 31 voices with Previous/Next without enabling audio. Preview remains explicit, M mutes outside input fields, and Mute stays at the top of Sound settings.
- A delayed browser audio resume can no longer undo a mute or start a cancelled preview.

No new dependencies, traffic fields, backend endpoints or native APK. Packet timing, route meaning, sound voices and stored preferences are preserved. All builds, tests and browser artifacts run in Actions; the published release record will contain the exact validation and delivery evidence.
