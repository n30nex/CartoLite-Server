# CartoLite Worldwide 0.12.2

- A cohesive CartoLite interface across Map, Netgraph, Chronoscope, Firehose and Pachinko, inspired by Beacon's restrained palette approach.
- Four coordinated palettes in Display: Aurora, Glacier, Ember and Violet. Each supports dark and light panels; Aurora also has the warm Streets/Paper companion.
- Consistent menus, fields, focus/selected states, inspector text, status colours and small control corners.
- Packet swatches now stay readable when panel and scene brightness differ. Chronoscope recent activity and Pachinko bucket labels follow the correct colour context.
- Existing saved preferences migrate safely. Palettes synchronize across ordinary views and tabs; Terminal keeps its custom colours and fonts.

Route/packet meaning, sound timing, camera state and physics are unchanged. Map and Netgraph remain the default pages; Terminal and Experimental views remain operator opt-ins. No native app or Labs are added.

All automated validation and synthetic screenshots run in Actions. Release
qualification, exact artifacts and public deployment evidence accompany the
published release.
