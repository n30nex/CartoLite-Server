# Chronoscope delivery

A session-local time sculpture beside Map, Netgraph and Terminal. Geographic groups remain recognizable on the Now plane; depth encodes elapsed observation time. Earlier traces remain distinct from newly arriving packet animation.

## Scope and order

1. Reuse public API v2, the existing geographic grouping, shared appearance, packet timing, sound and compact navigation. Keep all isolated public nodes available without fabricating links.
2. Add Sculpture, Slice and Flat views; a 30/60/120-second observation window; freeze/return-live, region selection, node and packet inspection, and accessible recent activity controls.
3. Validate dense and sparse synthetic scenes, desktop/phone layouts, themes, motion, frozen-view isolation, background resume, observer-only events, disconnected segments, graphics fallback and bounded retention. Keep existing topology/privacy/runtime performance checks.
4. Publish paired exact-commit images, deploy Canada after a fresh encrypted backup and isolated restore, qualify the public pages and update product links and private release records.

## Limits and meaning

The buffer holds at most 1,024 complete events and 4,096 segments for up to two minutes; a frozen view holds one additional bounded snapshot. Oldest complete events expire first and capacity trimming is disclosed. Nothing is stored across reloads or backfilled from retained route counts. Hidden and disconnected intervals remain unobserved. Slice shows a four-second interval around the selected moment. Sound plays visible fresh events only and is silent while frozen.

Canada keeps its exact region resolver. Worldwide keeps coordinate-derived grouping and its key-free installation. No new traffic endpoints, payloads, accounts or database are introduced. Depth is time, not terrain or RF propagation; confirmed segments are never joined across a gap.

## Release qualification

All builds, automated tests and browser artifacts run in GitHub Actions. The final release includes the pending long-session fixes and Terminal graphics-recovery hardening. A passing PR is not a deployment claim; immutable images, checksums, provenance and public/runtime verification remain required.
